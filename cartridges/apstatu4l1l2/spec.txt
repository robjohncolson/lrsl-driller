Topic 4.3 Content: Probability Definitions & Basic Rules
Key Concepts:

Sample space (S) — set of all possible outcomes
Probability of an event: 0 ≤ P(A) ≤ 1
P(S) = 1 (something must happen)
Complement rule: P(A^c) = 1 - P(A)
"At least one" = 1 - P(none)
Equally likely outcomes: P(A) = (favorable outcomes) / (total outcomes)

Vocabulary to drill:

Sample space
Complement (A^c or A')
Probability model
Legitimate probability distribution (all probabilities 0-1, sum to 1)

New Levels to Add (L12-L16 or similar)
Level: Sample Space Identification

Type: Multiple choice or short answer
Prompt: "List/identify the sample space for [scenario]"
Examples:

Rolling a die: {1, 2, 3, 4, 5, 6}
Flipping 2 coins: {HH, HT, TH, TT}



Level: Valid Probability Check

Type: Choice (Yes/No with justification)
Prompt: "Is this a valid probability model? Why or why not?"
Grading: Must identify if probabilities are 0-1 AND sum to 1
Common errors: Probabilities sum to more/less than 1, negative probability

Level: Complement Rule

Type: Number input
Prompt: "If P(A) = 0.35, find P(A^c)"
Answer: 0.65
Variation: "P(not raining) = 0.7, find P(raining)"

Level: "At Least One" Problems

Type: Number input with work
Prompt: "Find the probability of at least one success in [scenario]"
Key insight: P(at least 1) = 1 - P(none)
Common setup: Multiple independent trials

Level: Equally Likely Outcomes

Type: Number input (as fraction or decimal)
Prompt: "If all outcomes equally likely, find P([event])"
Formula: favorable / total
