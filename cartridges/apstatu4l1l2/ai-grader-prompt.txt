## Key Vocabulary for This Topic

### Topics 4.1-4.3 (Basic Probability)
- Random process: A situation where all possible outcomes are known, but individual outcomes are unpredictable
- Outcome: The result of a single trial of a random process
- Event: A collection of outcomes from a random process
- Simulation: A way to model random events such that simulated outcomes closely match real-world outcomes
- Empirical probability: Probability estimated by performing many trials and calculating relative frequency
- Law of Large Numbers: As the number of trials increases, simulated probabilities get closer to the true probability
- Independence: Knowing the result of one trial does not affect the probability of future trials
- Gambler's fallacy: The mistaken belief that past outcomes affect future probabilities
- Sample space (S): The set of all possible non-overlapping outcomes for a random process
- Complement: The event that A does NOT happen, denoted A' or A^c. P(A') = 1 - P(A)
- Probability model: A valid model where each probability is between 0 and 1 AND all probabilities sum to exactly 1
- "At least one": Finding P(at least one) is easiest using the complement: P(at least 1) = 1 - P(none)
- Equally likely outcomes: When all outcomes are equally likely, P(A) = (favorable outcomes) / (total outcomes)

### Topic 4.4 (Mutually Exclusive Events)
- Mutually exclusive (disjoint): Two events that CANNOT occur at the same time. P(A ∩ B) = 0
- Joint probability: The probability that BOTH events occur: P(A ∩ B) = (intersection count) / (grand total)
- Intersection (∩): "AND" - the outcomes that are in BOTH events

### Topic 4.5 (Conditional Probability)
- Conditional probability: P(B|A) = probability of B GIVEN that A has occurred
- Formula: P(B|A) = P(A ∩ B) / P(A)
- General multiplication rule: P(A ∩ B) = P(A) × P(B|A)
- Order matters: P(A|B) ≠ P(B|A) in general! Different denominators give different results
- "Given" or |: Restricts the sample space to only the outcomes where the condition occurred

### Topic 4.6 (Independent Events & Unions)
- Independent events: Knowing one occurred doesn't change the other's probability
- Two ways to check: P(A|B) = P(A), or P(A ∩ B) = P(A) × P(B)
- Multiplication rule (independent): P(A and B) = P(A) × P(B) - only for independent events!
- Addition rule: P(A or B) = P(A) + P(B) - P(A ∩ B)
- For mutually exclusive: P(A or B) = P(A) + P(B) since P(A ∩ B) = 0
- IMPORTANT: Independent ≠ Mutually Exclusive! Independent events CAN occur together.

### Topic 4.7 (Random Variables & Distributions)
- Random variable: A numerical outcome of random behavior, labeled with capital letters (X, Y, W)
- Discrete random variable: Takes countable values with gaps between them (counts: 0, 1, 2, 3...)
- Continuous random variable: Takes any value in an interval (measurements: time, length, weight)
- Valid probability distribution: (1) Each P(X) between 0 and 1, (2) All P(X) sum to exactly 1
- Shape of distribution: Symmetric, skewed left (tail extends left), skewed right (tail extends right), uniform
- Calculating probabilities: Add P(X) values for all X in the specified range

### Topic 4.8 (Parameters of Random Variables)
- Mean (expected value): μ = Σ[x · P(x)] - the long-run average
- Standard deviation: σ = √[Σ(x - μ)² · P(x)] - typical deviation from mean
- Interpretation: Mean is the long-run average; SD is how much values typically vary from the mean
- ALWAYS include context and units when interpreting parameters!

### Topic 4.9 (Combining Random Variables) ⚠️ VARIANCE TRAP ALERT
- Linear transformation Y = a + bX:
  - Mean: μY = a + b·μX (transform the mean like any value)
  - SD: σY = |b|·σX (constant 'a' DOESN'T affect spread, only multiplier 'b' does)
- Sum of independent random variables:
  - Mean: μ(X+Y) = μX + μY (means add normally)
  - Variance: σ²(X+Y) = σX² + σY² (variances ADD)
  - SD: σ(X+Y) = √(σX² + σY²) — NOT σX + σY! ⚠️
- Difference of independent random variables:
  - Mean: μ(X-Y) = μX - μY (means subtract normally)
  - Variance: σ²(X-Y) = σX² + σY² (variances STILL ADD!)
  - SD: σ(X-Y) = √(σX² + σY²) — SAME as sum! ⚠️
- INDEPENDENCE is required for the variance addition rules
- THE VARIANCE TRAP: Students often add SDs directly or subtract variances for X-Y. Both are WRONG!

### Topic 4.9 (Combining Random Variables)
- Linear transformation Y = a + bX: For mean, μY = a + b·μX. For SD, σY = |b|·σX (constant doesn't affect spread!)
- Sum of means: μ(X+Y) = μX + μY - just add normally
- Difference of means: μ(X-Y) = μX - μY - just subtract normally
- VARIANCE TRAP: For SD of sum/difference of INDEPENDENT random variables:
  - σ(X+Y) = √(σX² + σY²) - NOT σX + σY!
  - σ(X-Y) = √(σX² + σY²) - SAME formula! Variances ALWAYS add!

### Topic 4.10 (Binomial Distribution)
- BINS conditions: Binary outcomes, Independent trials, fixed Number of trials, Same probability each trial
- Binomial formula: P(X=x) = C(n,x) · p^x · (1-p)^(n-x)
- Cumulative: P(X ≤ k) = sum of binomial probabilities; P(X ≥ k) = 1 - P(X ≤ k-1)
- Components: n = trials, p = success probability, x = successes

### Topic 4.11 (Binomial Parameters & Unusualness)
- Mean: μ = n·p
- SD: σ = √[n·p·(1-p)]
- Interpretation: Mean = long-run average successes; SD = typical variation around the mean
- 2-SD rule: Unusual if outside μ ± 2σ

### Topic 4.12 (Geometric Distribution)
- Geometric setting: count trials until first success
- Geometric formula: P(X=x) = (1-p)^(x-1) · p
- Mean: μ = 1/p
- SD: σ = √[(1-p)/p²]
