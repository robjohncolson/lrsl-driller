KEY CONCEPTS BY TOPIC:

5.1 Sampling Variability:
- Different random samples from the same population produce different statistics
- This variation is called SAMPLING VARIABILITY
- A single sample statistic is unpredictable, but the distribution of all possible sample statistics is predictable
- The sampling distribution is centered at the true population parameter

5.2 Normal Distribution:
- Z-score formula: z = (x - μ) / σ
- Area under the curve = probability
- Proportion, percent, probability are interchangeable
- AP exam solutions MUST include: (1) Define random variable, (2) Show normal distribution, (3) Identify parameters, (4) Value of interest + direction, (5) Correct probability
- Inverse normal: given area, find the cutoff value using z = invNorm(area), then x = μ + z·σ

5.2 Assessing Normality:
- Check: unimodal, roughly symmetric, bell-shaped
- Empirical rule: 68-95-99.7
- For binomial: need large enough n for normal approximation
- Small n with skewed proportion → NOT normal

5.2 Linear Combinations:
- Mean of X ± Y: μ(X±Y) = μX ± μY (straightforward)
- SD of X ± Y: σ(X±Y) = √(σX² + σY²) — ALWAYS add variances, even for differences!
- If X and Y are independent and normal, then X ± Y is also normal
- Common trap: students add/subtract SDs directly instead of working with variances

5.3 Central Limit Theorem (CLT):
- The CLT states: when sample size is sufficiently large, the sampling distribution of x̄ is approximately normal, regardless of the population shape
- Conditions: sample values must be independent AND n must be sufficiently large
- If population is normal → sampling distribution of x̄ is normal for ANY n (even n = 1)
- If population is non-normal → need n ≥ 30 (larger for extremely non-normal populations)
- Sampling distribution of x̄: mean = μ, SD = σ/√n
- As n increases: shape becomes more normal, spread decreases (σ/√n shrinks), center stays at μ
- Common confusion: students say "larger samples have less variability" without specifying variability OF WHAT (the sampling distribution, not the sample itself)

5.3 Randomization Distributions:
- A randomization distribution is a collection of statistics generated by repeatedly randomly reassigning response values to treatment groups
- Purpose: determines how likely the observed result would be if it happened by chance alone
- Process: keep same data values, randomly shuffle which group each value belongs to, calculate statistic (e.g., difference in means), repeat many times
- P-value = (number of simulations as extreme as or more extreme than observed) / (total simulations)
- Small p-value (typically < 0.05) → observed result unlikely by chance → convincing evidence of treatment effect
- Large p-value → observed result could plausibly happen by chance → not convincing evidence
- Key difference from sampling distribution: randomization reshuffles existing experimental data; sampling distribution draws new samples from a population
