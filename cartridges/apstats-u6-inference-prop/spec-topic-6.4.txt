Framework Skills Targeted (Topic 6.4)
--------------------------------------
- VAR-6.D: Identify null and alternative hypotheses for a population proportion [Skill 1.F]
  - VAR-6.D.1: Null = assumed correct unless evidence otherwise; Alt = what we collect evidence for
  - VAR-6.D.2: Null contains equality (=); Alt contains strict inequality (<, >, or !=)
  - VAR-6.D.3: H0: p = p0
  - VAR-6.D.4: Ha: p < p0, p > p0, or p != p0 (one-sided vs two-sided)
  - VAR-6.D.5: Null specifies a value indicating no difference or effect

- VAR-6.E: Identify appropriate testing method [Skill 1.E]
  - VAR-6.E.1: One-sample z-test for a population proportion

- VAR-6.F: Verify conditions for testing a population proportion [Skill 4.C]
  - VAR-6.F.1: Check independence (random sample, 10% condition) AND normality
    - np0 >= 10 AND n(1-p0) >= 10 (using p0, NOT p-hat!)

Key Pedagogical Points from Lecture Videos
-------------------------------------------
1. Null hypothesis = "no difference" or "no change" -- always contains "="
2. Alternative hypothesis = what researchers hope to show with data
3. One-sided (< or >) vs. two-sided (!=) -- determined by research question
4. MUST define the parameter p in context (e.g., "p = proportion of ALL students...")
5. NEVER use p-hat in hypotheses -- hypotheses are about population, not sample
6. Alternative should be stated BEFORE data collection (not after seeing data)
7. Procedure: one-sample z-test for a population proportion
8. Conditions for z-test use p0 (null value), NOT p-hat, in large counts check
   - This differs from CI conditions which use p-hat
9. When population size unknown, state assumption about 10% condition

Common Student Errors (from transcripts & framework)
-----------------------------------------------------
- Using p-hat instead of p in hypotheses
- Putting inequality in the null hypothesis
- Writing hypotheses about the sample instead of population
- Using p-hat instead of p0 in the large counts condition check
- Choosing wrong direction for alternative (one-sided vs two-sided)
- Defining parameter using sample language ("the proportion who said") vs
  population language ("the proportion who would say")
- Confusing z-test conditions with z-interval conditions

Name: "6.4a: State the Null Hypothesis"
Animation: assets/StateNull.mp4
Unlocked by: { gold: 1 } (after L16 capstone)

Type: Multiple choice / dropdown
Prompt: Given a research scenario with a claimed proportion, identify the correct H0.

Input layout:
  - nullAnswer (dropdown): "Select the correct null hypothesis"
    Options: 4 choices, e.g.:
      "H0: p = 0.40"
      "H0: p-hat = 0.40"
      "H0: p > 0.40"
      "H0: p != 0.40"

Generator logic:
  - Draw from a scenario bank with context, claimed proportion p0
  - Correct answer is always H0: p = p0
  - Distractors: uses p-hat, uses inequality, wrong p0 value

Grading:
  - E: Correct null hypothesis selected
  - I: Any wrong answer

Animation concept (StateNull.mp4):
  3Blue1Brown style. Show a balance scale starting level (equilibrium = "no
  difference"). Text "H0: p = p0" appears. Animate what "null" means:
  the default state of the world. Show a normal curve centered at p0.
  Highlight that the null ALWAYS uses "=" sign. Visual mnemonic: null = neutral.

  - nullHypothesis:
    E: Contains "p = {p0}" or "p={p0}" (correct value, uses p not p-hat)
    P: Correct p0 value but formatting issues
    I: Wrong value, uses p-hat, or uses inequality

    E: Contains correct direction symbol and p0 value (e.g., "p > 0.4")
    P: Correct direction but formatting issues
    I: Wrong direction, uses p-hat, or uses equality
  - paramDef:
    E: Mentions "proportion" + "all" (or equivalent population language) + context
    P: Has proportion + context but missing population reference
    I: Uses sample language, or blank/irrelevant
